# FINAL SETUP — MINIMUM INPUTS

The Ready-Made version is designed so you do **not** have to build the lobby UI yourself.

## You provide/connect only these production-specific things

1. Import the SL Lobby System package.
2. Put your final one-time storyline introduction video into the project and assign it to `Introduction Video`.
3. Put/connect your real Character System character meshes/prefabs.
4. Connect the real Pet/Equipment/Inventory/Skills/Quest/Social/Server systems when those systems are ready.
