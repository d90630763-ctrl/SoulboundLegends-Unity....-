# Ready-Made UI Specification

## User's final correction
The lobby system must arrive with the UI already built. The developer should not have to create every button, page, panel, banner, card, navigation area, pressed state or background manually.

### Included by the package
- All major lobby pages
- Ready-made page headers
- Ready-made navigation buttons
- Normal/highlighted/pressed/disabled button states
- Page backgrounds and panel graphics
- Loading graphics
- Intro background
- Notification graphics
- Mode-card graphics
- Banner graphics
- UI icon set
- Sample UI sound
- Sample intro video
- Ready-made settings category page
- Ready-made emote and entrance-emote pages
- Ready-made mode-selection page
- Ready-made social/profile/mail pages
- Ready-made inventory/equipment/vault/character page layouts
- Ready-made store/draw/event/quest pages

### Developer input kept minimal
The developer supplies/connects:
1. The final one-time storyline introduction video.
2. The actual Character System and character meshes.
3. The actual Pet/Equipment/Inventory/etc. systems and their live data/controllers.
4. The server/authentication implementation and credentials.
5. Final production art only when the developer chooses to replace the supplied defaults.

The package does not require the developer to manually construct every UI page before the lobby can run.
