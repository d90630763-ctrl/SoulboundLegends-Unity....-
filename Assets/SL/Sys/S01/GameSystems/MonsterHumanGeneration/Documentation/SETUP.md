# System 01 Setup

1. Copy `Assets/GameSystems/MonsterHumanGeneration` into your Unity project.
2. Create a Generation Profile from `Assets > Create > Game Systems > Monster Human > Generation Profile`.
3. Enter body and appearance descriptions.
4. Open `Tools > Game Systems > Monster & Human Generation`.
5. Assign the profile.
6. Press Validate.
7. Press Generate Assets.
8. Find the generated prefab under `Assets/GeneratedMonsterHuman/<name>/`.

Example:
`Dark blue body with three silver stripes across the back and glowing red flakes around the shoulders.`

The package provides deterministic local generation. External AI/model services are integration providers, not fabricated bundled services.
