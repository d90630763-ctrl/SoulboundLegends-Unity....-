# SL — Unity 6000.5.6f1 compatibility

This package targets **Unity 6000.5.6f1**.

The integrated feature set is preserved from the previous final combined package. The Unity Editor metadata has been migrated from 6000.3.25f1 to 6000.5.6f1, while the source systems remain intact.

## Important

This is a project-version/package migration, not a claim that every system has already passed a real Unity 6000.5.6f1 import, compile, Play Mode, Android build, multiplayer, or device test. Those require the actual 6000.5.6f1 Editor and its installed modules.

Unity 6000.5.6f1 is an official Unity 6 release (July 29, 2026). Its release notes include Android changes and fixes.

## First launch

1. Install Unity **6000.5.6f1**.
2. Install Android Build Support, Android SDK & NDK Tools, and OpenJDK if Android builds are required.
3. Extract this archive.
4. Open the `Game` folder in Unity 6000.5.6f1.
5. Let Unity finish package/asset import.
6. Resolve any package/API migration prompts before entering Play Mode.
7. Test the project using the included testing handoff.

Do not delete or overwrite the `Assets/SL` integrated systems during the first import.
