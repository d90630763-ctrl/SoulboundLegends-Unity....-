# Soulbound Legends — Rebuilt Unity 6 Package

Open **`SL/Game`** with Unity **6000.5.6f1**. The project now includes a custom one-click generation window at **Soulbound Legends → Game Builder**.

Follow `Game/Assets/Documentation/ONE_CLICK_BUILDER_GUIDE.md` for setup, intro-video assignment, scene generation, validation, and Android build steps.

This package includes an implemented editor-generation pipeline and existing game systems, but it has not been compiled or playtested in the Unity Editor in this environment. Generated actors use primitive base meshes; premium character art, animation quality, and external online services require further assets, setup and testing. Do not treat the ZIP as a verified production-ready AAA release until it passes editor compilation, Play-mode tests and Android-device tests.


## Visual generation quality upgrade
This package adds a higher-resolution multi-scale procedural terrain mesh, layered modular building details, denser shared procedural character surfaces, and configurable lighting/performance defaults. See Game/README_SOULBOUND_BUILDER.md for scope and limitations.
