# Soulbound Legends — Unity 6 project bundle

**Unity Editor target:** `6000.5.6f1`  
**Unity project folder:** `Game/` (relative to this `SL` folder)  
**Backend/service source:** `Srv/` (separate deployment and configuration required)

## Open in Unity
1. Extract this package.
2. Open Unity Hub and choose **Add project from disk**.
3. Select the `SL/Game` folder. Do not select the outer `SL` folder.
4. Wait for Package Manager and script compilation to finish.
5. Open **Soulbound Legends → Game Builder**.
6. Assign an intro VideoClip if you have one, then click **BUILD GAME**.
7. Click **VALIDATE GENERATED PROJECT** and inspect `Game/Assets/Documentation/BUILDER_LAST_REPORT.md`.
8. To make an APK, install Unity Android Build Support (SDK, NDK and OpenJDK) and click **BUILD ANDROID APK**.

## Character-generation upgrade
The runtime actor factory now builds stylized fantasy characters from generated parametric meshes, including body anatomy, facial features, hair, layered tunics/jackets, belts, shoulder armor, bracers, boots, elemental accents and accessories. It creates transform bones and supports procedural idle, locomotion, attack, heavy-attack combo phases, block, dodge and jump motions. Optional look/hand targets are exposed for lightweight procedural IK alignment.

The `01_CharacterCreation` scene generated by Build Game now includes three front-facing generated 3D character previews. Existing Change Element and Randomize Look UI actions affect the primary preview. Combat scenes include Attack, Heavy Attack, Block and Dodge controls. System 01's mesh profile generator also creates a detailed composite procedural mesh asset and higher-resolution patterned textures.

## GitHub / Unity Build Automation
- Upload the complete `SL` folder to the repository, including `Game/Assets`, `Game/Packages`, and `Game/ProjectSettings`.
- The Unity project is nested at `SL/Game`; configure the build service's Unity project path to that folder if the service asks for a project subdirectory. If the service only accepts a project at repository root, upload the contents of `SL/Game` at the repository root and keep `Srv/` separately.
- Keep `.meta` files and `Packages/manifest.json` / `packages-lock.json` in Git. Do not upload `Library`, `Temp`, `Obj`, or local secrets.
- Unity Build Automation compiles an existing Unity project; it does not automatically create missing source code or deploy the backend services.

## Honest quality and validation notes
This is an automated stylized character-generation foundation, not a guarantee of Free Fire-equivalent commercial character art. It generates geometry and motion procedurally, but does not magically create photorealistic sculpting, production-grade motion capture, a Unity Humanoid Avatar with full retargeting, or finished multiplayer hosting. Character quality, performance, input behavior, scene generation, and Android compatibility must be checked in the target Unity Editor and on a device. This environment cannot run Unity Editor compilation or produce a verified Android APK.
